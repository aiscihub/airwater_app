# Material crystal-structure images

Drop a PNG here named after the material's slug (lowercase, spaces to hyphens)
and the "Top recommendation" panel will pick it up automatically — no code
changes needed. If the file is missing, the image area just stays hidden.

Expected filenames for the current candidate catalog:

- `mof-303.png`
- `mof-801.png`
- `mil-160.png`
- `cau-10-h.png`
- `mof-841.png`
- `uio-66-nh2.png`

Recommended: roughly square, at least 400x400px, transparent or white background.

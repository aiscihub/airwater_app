# AirWater AI Judge Demo Checklist

## Before presentation day

- Install dependencies from `requirements.txt`.
- Run `python scripts/smoke_test.py`.
- Start the app with `python app.py`.
- Confirm the app opens at `http://127.0.0.1:8000`.
- Test the Desert solar and Mild hybrid presets.
- Confirm all four tabs open and charts resize correctly.
- Keep the default climate source on **Offline demo profile**.
- Close unnecessary browser tabs and notifications.
- Use a 16:9 display at 100 percent browser zoom.
- Keep the application package and video recording on a local drive.

## Recommended backup plan

- Record a complete walkthrough before the event.
- Keep `docs/ui_preview.png` available as a visual fallback.
- Do not depend on NASA POWER during the live demonstration.
- Keep the original source ZIP and a second extracted copy.

## Claims to use

- Functional proof-of-concept AI application
- Climate-aware MOF screening
- Simulated research estimate
- Candidate prioritization for laboratory testing
- Explainable ranking and operating plan

## Claims to avoid

- Certified MOF
- Proven drinking-water system
- Guaranteed liters per day
- Commercial manufacturing process
- Replacement for laboratory testing
